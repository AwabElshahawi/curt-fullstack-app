# Team Project Management System

A full-stack web app that helps teams organize projects, break them into tasks, assign tasks to members, and track status and priority. Built for the Cairo University Racing Team Software Development Team technical task (Season 26-27).

## Overview

The system lets users create an account, log in, and manage their own projects. Each project can have members and tasks. Tasks have a title, description, status (To Do, In Progress, Done), priority (Low, Medium, High), and an assignee who must be a member of the project. Project owners have full control, while members can view the project and update the status of the tasks assigned to them.
